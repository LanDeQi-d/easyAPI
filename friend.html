默认安装到 D 盘，可选择其他目录。请先退出正在运行的旧版，用户资料保留在 AppData。

GitHub Releases

如何开始

  1. 新建对话，填写角色名称、提示词、用户称呼和头像。

  2. 手动填写兼容接口或读取 easy API 设置，再创建朋友。

  3. 发送消息；按对话查看保存在本机的历史，可停止回复或删除记录。

能力与数据边界

本地对话与配置留在用户资料目录，在线请求会发送到用户选择的模型服务。

角色支持表情或本地图片头像；手动密钥系统加密，不会返回给界面。仅支持兼容 Chat Completions 接口，默认发送最近40条消息，记录完整保留。
